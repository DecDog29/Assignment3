# YOWD - Your Order We Deliver (SWE30003 Assignment 3)

Console application implementing four business areas of the YOWD delivery
system, written in Python. Design basis: Assignment 2 object design.

## Platform used for development and testing
- OS: Windows 11 (edit if different)
- IDE: Visual Studio Code
- Python: 3.11+

## Setup and run
```
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt
python -m yowd                  # run the application
```
Data is stored as JSON files in `data/` (created on first run).
